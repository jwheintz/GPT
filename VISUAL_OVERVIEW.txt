                           DATA FLOW EXAMPLE

1. Student clicks [🎨 Color Effect] button
                    ▼
2. WebSocket message sent to server
   { type: 'obs_command', command: 'toggle_filter', 
     params: { sourceName: 'Camera', filterName: 'ColorCorrection' } }
                    ▼
3. Server validates:
   ✓ Kill switch OFF?
   ✓ Rate limit OK?
   ✓ Authenticated?
                    ▼
4. Server sends to OBS via WebSocket:
   obs.call('SetSourceFilterEnabled', ...)
                    ▼
5. OBS toggles the filter
   [Filter is now visible on your camera feed! 🎥]
                    ▼
6. Server broadcasts confirmation to ALL connected clients:
   { type: 'filter_toggled', filterName: 'ColorCorrection', enabled: true }
                    ▼
7. Everyone's activity feed updates:
   "✓ Color Effect enabled"
