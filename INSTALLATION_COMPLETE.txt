🆘 QUICK TROUBLESHOOTING:

  Problem: "Cannot connect to OBS"
  → Check OBS WebSocket is enabled (Tools → WebSocket Server Settings)
  
  Problem: "Students can't connect"
  → Make sure ngrok is running and share the HTTPS URL
  
  Problem: "Buttons don't work"
  → Filter/source names must match EXACTLY (case-sensitive)
  
  Problem: "Password doesn't work"
  → Use password HASH in .env, not plain text
  
  More help in FAQ.md!

💡 PRO TIPS:

  • Test everything yourself before going live with students
  • Start with kill switch ON, explain system, then turn OFF
  • Use the kill switch liberally - it's there for a reason!
  • Start with just a few buttons, add more gradually
  • Name filters clearly in OBS (no spaces, case-sensitive)
  • Have a backup plan - be ready to teach without it
  • Monitor the activity feed during class
  • Students will LOVE this! 🎉
