Classroom Controls

This page sends small “class participation” commands to the instructor’s OBS computer. If the instructor disables controls, everything stops immediately.

Not connected
This is NOT hosted on Squarespace; Squarespace hosts this page, your relay runs elsewhere.
If the instructor rotates tokens or locks controls, requests will stop.

Student buttons

These buttons are safe because the relay enforces a server-side allowlist.

Instructor setup: edit relay/allowlist.json on the relay server and (optionally) the config block in this HTML.

What to tell students

If buttons do nothing, controls may be temporarily disabled by the instructor. This is intentional so class can continue.
